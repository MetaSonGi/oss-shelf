## 목록 페이지

`index.html`을 내려받아 브라우저에서 열면 검색, 분류, 별 수 정렬, 확인 체크, 개인 메모를 사용할 수 있습니다. 설치나 서버가 필요 없습니다. 체크와 메모는 같은 브라우저의 localStorage에 저장되며 GitHub에는 자동 저장되지 않습니다. 다른 브라우저로 옮길 때는 ‘메모 내보내기’와 ‘메모 가져오기’를 사용하세요.

비공개 저장소로 생성했으며 GitHub Pages는 설정하지 않았습니다.

## 메타데이터

별 수와 라이선스 표기는 확인일의 GitHub API 응답입니다. `NOASSERTION`은 API가 표준 라이선스를 식별하지 못했다는 뜻입니다. 각 저장소의 라이선스 원문과 모델·의존성 조건은 해당 저장소에서 확인하세요. API 사용료나 모델 실행 환경은 이 목록 페이지에 포함되지 않습니다.
